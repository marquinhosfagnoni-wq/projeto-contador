Tomorrowland — Site de Divulgação de Evento

Site desenvolvido como projeto acadêmico (Projeto Contador), com o objetivo de divulgar um evento fictício — um festival de música eletrônica inspirado no Tomorrowland — e converter visitantes em ingressos cadastrados.

🔗 Site publicado: https://marquinhosfagnoni-wq.github.io/Projeto-contador/ 🔗 Repositório: https://github.com/marquinhosfagnoni-wq/Projeto-contador

Sobre o projeto

O evento: um festival de música eletrônica, com data marcada para 09 de outubro de 2026, em São Paulo - SP. O site foi pensado para um público jovem (18 a 35 anos), com uma proposta visual de fundo escuro, tipografia grande e fotos em destaque, remetendo ao clima noturno de um festival.

Funcionalidades
Contador regressivo até a data do evento, atualizado a cada segundo em JavaScript (dias, horas, minutos e segundos)
Banner principal em tela cheia, com chamada para ação e botão de ingresso
Menu de navegação fixo, com rolagem suave por âncora entre as seções
Galeria de imagens em carrossel, com botões de avançar e voltar
Layout responsivo, adaptado para celular, tablet e desktop
Página de detalhes do evento, com informações sobre o festival e contato da organização
Formulário de cadastro de ingresso, com validação de campos via HTML5 (e-mail, telefone, data e quantidade) e seleção do tipo de ingresso (comum, VIP ou Premium)
Páginas do site
Arquivo	Conteúdo
index.html	Página inicial — banner, contador regressivo, galeria e navegação
contato.html	Detalhes do evento e informações de contato da organização
cadastro.html	Formulário de cadastro para ingressos
Tecnologias utilizadas
HTML5 — estruturação semântica das páginas (header, section, footer)
CSS3 — estilização, paleta de cores, tipografia, layout com flexbox/grid, responsividade via media queries e animações
JavaScript — lógica do contador regressivo, carrossel da galeria e menu de navegação
